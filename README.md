## The Complete Python Developer Course

This is a four-phase Python course that starts from absolute zero. No prior
programming experience, no computer science background, no math beyond basic
arithmetic. If you can use a mouse, a keyboard, and open a web browser, you
can start here.

The course is built around one rule: type every example yourself. Never
copy-paste. Typing code, including your own typos and the error messages that
follow, is how syntax actually gets into your fingers and your brain. This is
the single biggest difference between people who finish and people who quit
partway through.

### Who This Is For

Anyone starting from zero. A career changer, a student, a hobbyist, someone
who wants to automate their own work. You need a computer, an internet
connection, and the willingness to actually type code rather than just read
about it.

If you already know some Python, the later phases are still worth your time.
Object-oriented programming and concurrency are substantial topics on their
own. But the course is written for, and tested against, a complete beginner's
starting point.

### What's In Here

Four phases, seventeen lessons each, roughly. Every lesson follows the same
structure: Why This Matters, Learning Objectives, the lesson itself, Common
Mistakes to Avoid, and a Lesson Project. Nothing is decorative. Every lesson
exists because a later lesson depends on it.

#### Phase 0: Course Introduction

The roadmap and the rules. Explains what the course covers, how it's
structured, and why Python specifically. Read this once before starting
Phase 1.

#### Phase 1: Python Essentials

Everything from your first program to packaging your own code. Variables,
operators, control flow, loops, string manipulation, lists, tuples,
dictionaries, sets, comprehensions, functions, type hints, file handling,
JSON, error handling, packages, virtual environments, and the everyday
standard library.

Ends with a Personal Library Manager capstone.

#### Phase 2: Object-Oriented Python

Modeling real things as your own types. Classes and objects, instance
methods, class and static methods, inheritance, encapsulation, property
decorators, magic methods, decorators, abstract base classes, and dataclasses.

Ends with a Library Management System capstone.

#### Phase 3: Advanced Python

Writing production-grade Python. Command-line tools, system automation,
working with APIs, environment configuration, logging, scheduled tasks,
iterators, generators, functools, context managers, threading,
multiprocessing, asyncio, debugging, profiling, and design patterns.

Ends with an Automated Site Monitor capstone that uses every technique from
the entire course.

### What You'll Be Able to Do

By the time you finish Phase 3, you'll be able to write clean, idiomatic
Python from scratch. You'll design your own classes and object hierarchies.
You'll build CLI tools, file automation, generators, context managers, and
concurrent programs. You'll know how to profile and debug code when it
misbehaves. And you'll have taken a project from a blank folder all the way to
something you could genuinely hand to someone else.

None of this is theoretical. Every one of those bullet points is a capstone
project you'll have built with your own hands by the time you reach it.

### How to Use This

Read the Phase 0 document first. It lays out the full roadmap and the rules
you're working under. Then start Phase 1, Lesson 1.1, which answers "why
Python, specifically?" before you write a single character of code. Lesson 1.2
walks through installing Python and running your very first program.

Each phase builds directly on the ones before it. Phase 3's capstone genuinely
uses something from every single phase that came before it. Don't skip
around.

### A Note on Structure

There's a second, smaller promise in this course: you will never be asked to
use a piece of syntax that hasn't been explained yet. If a code example uses
something new, that lesson teaches it first. If you ever find yourself
confused by a symbol or a function you don't recognize, that's a sign to go
back one lesson, not a sign that you're behind.

Keep the Phase 0 document. Every phase from here on assumes you've read it
once, and builds directly on the roadmap and rules laid out there.
